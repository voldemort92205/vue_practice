# Practice 8: Opendata Demo

This practice is to demo the front (vue) and [backend](https://github.com/voldemort92205/opendataDemoBackend) skills by using open data.

More opensource data will be added into this site in the future.

## Demo
1. Run backend server from (this repo)[https://github.com/voldemort92205/opendataDemoBackend] with the following command
```
node app.js
```

2. Open the browser page with this vue
